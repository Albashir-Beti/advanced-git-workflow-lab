
# Advanced Git Workflow Lab

A hands-on project for practising Git version control using GitHub and Bitbucket.

## Learning Objectives

- Create and clone repositories
- Create and manage branches
- Stage and commit changes
- Revert commits
- Push, pull, and fetch changes
- Merge and rename branches
- Create, review, merge, and revert pull requests

## Tools

- Git
- GitHub
- Bitbucket
- Visual Studio Code
- PowerShell
